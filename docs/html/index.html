IACForge · YAML Reference

Reference

IACForgeは、インフラストラクチャをモデルとして定義し、様々な表現を生成するためのフレームワークです。「インフラは知識」という哲学に基づき、モデルを唯一の信頼できる情報源とします。

このリファレンスは、YAMLファイル作成のための完全版リファレンスです。

クイックスタート

CLIを使用してモデルの検証・情報取得・レンダリングができます。

iacforge validate model.yaml
iacforge info model.yaml
iacforge render --format markdown model.yaml
iacforge query --kind server model.yaml

コアコンセプト

  • Entity – インフラ内のすべてのオブジェクトを表す基本的な単位。
  • Relation – Entity間のピア・ツー・ピアの関係。
  • Graph – EntityとRelationのコレクション。
  • Ownership – Entity間の階層関係（ツリー構造）。
  • Artifact – Rendererの生成出力。
